# ETF分析系统改造完成报告

## 一、改造概览

基于对东方财富/天天基金（fund.eastmoney.com）的深入研究，已完成对现有ETF分析系统的改造。

### 学习成果

天天基金网核心功能模块:
- **折溢价监控**: IOPV实时估值 + 折价率/溢价率自动计算
- **资金流向**: 主力/超大单/大单/中单/小单净流入分析
- **同类排名**: 百分位排名 + 四分位评级(优秀/良好/一般/不佳)
- **四家评级**: 上海证券、招商证券、济安金信、晨星
- **持仓明细**: 股票/债券持仓占比、行业配置、持有人结构
- **收益测算器**: 基于申购金额+历史业绩模拟收益
- **多维筛选**: 基金公司、类型、规模、费率、评级、收益率组合筛选

### 数据接口

通过AKShare可获取:
- `fund_etf_spot_em()` — 37列实时行情(含IOPV、折价率、资金流)
- `fund_etf_hist_min_em()` — 分时K线(1/5/15/30/60分钟)
- `fund_info_index_em()` — 指数型基金信息(跟踪标的、跟踪方式)
- `fund_name_em()` — 全量基金基本信息

## 四、技术架构

### 数据流

```
AKShare fund_etf_spot_em() [37列实时数据]
    ↓
dip_monitor.py → IOPV折溢价计算 → 预警阈值检测 → Markdown报告
fund_flow.py   → 资金流分解   → 量价背离检测 → 预警报告
ranking.py     → 百分位排名   → 四分位评级   → 排名报告
holdings_overlap.py → Jaccard+加权重叠 → 行业余弦相似度 → 重叠报告
return_calculator.py → 历史收益率→ 年化估算 → 定投vs单笔比较
```

### 核心算法

1. **折溢价预警**: 溢价>3%预警，>10%极端警告；折价<-2%预警，<-5%极端警告
2. **资金流向分类**: 6种模式(量价齐升/主力出货/主力吸筹/量价齐跌/散户追高/散户恐慌)
3. **持仓重叠**: Jaccard相似度×0.3 + 加权重叠率×0.7，行业配置余弦相似度
4. **排名百分位**: (排名-1)/(总数-1)×100，四分位映射

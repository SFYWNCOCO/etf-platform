# 东方财富/天天基金 ETF 分析系统 - 功能模块研究报告

## 一、平台概览

天天基金网（fund.eastmoney.com）是东方财富旗下专业基金交易平台，提供大数据多维度基金分析。

---

## 二、核心功能模块

### 2.1 数据展示层

| 模块 | URL | 说明 |
|------|-----|------|
| ETF基金净值 | `fund.eastmoney.com/ETFN_jzzzl.html` | 场内交易基金净值、折价率、溢价率查询 |
| 场内交易基金排行 | `fund.eastmoney.com/data/fbsfundranking.html` | 近1周/1月/3月/6月/1年/2年/3年/今年来/成立来收益排名 |
| 开放式基金排行 | `fund.eastmoney.com/data/fundranking.html` | 自定义排行、按基金公司筛选 |
| 基金筛选 | `fund.eastmoney.com/data/fundshaixuan_1128.html` | 按基金公司、类型、投资风格、交易状态、回报率、规模等多维筛选 |
| 定投排行 | `fund.eastmoney.com/dingtou/` | 定投收益率排行 |
| 基金评级 | 各基金公司页面 | 上海证券/招商证券/济安金信/晨星四家评级 |
| 新发基金 | `fund.eastmoney.com/data/` | 在售/新成立基金一览 |

| 基金公司 | 基金公司一览 | 成立日期、旗下基金数、管理规模、天相评级 |

### 2.2 ETF详情页功能（以159941为例）

- **基本信息**：基金名称、代码、类型、规模、基金经理、成立日期、管理人、托管人
- **净值走势**：单位净值、累计净值、日增长率、历史净值表
- **阶段涨幅**：近1周/1月/3月/6月/近1年/近2年/近3年
- **同类排名**：同类平均对比、四分位排名（优秀/良好/一般/不佳）
- **跟踪标的**：基准指数表现对比
- **持仓明细**：股票持仓占比、债券持仓、前十持仓合计
- **规模变动**：基金份额/规模变化趋势
- **持有人结构**：机构/个人持有比例
- **资产配置**：行业配置、资产配置
- **重大变动**：投资组合重大调整
- **基金经理**：历任基金经理、任职时间、任期回报
- **基金公告**：最新公告列表
- **基金资讯**：相关新闻
- **基金吧**：社区讨论
- **业绩评价**：基金特点、换手率
- **收益测算器**：根据申购金额和过往业绩计算预期收益
- **折溢价/IOPV**：ETF实时估值 vs 交易价格

### 2.4 数据接口（AKShare可调用）

| 接口 | 说明 | 字段数 |
|------|------|--------|
| `fund_etf_spot_em()` | ETF实时行情-东财 | 37列：代码、名称、最新价、IOPV、折价率、涨跌幅、成交量、成交额、主力净流入等 |
| `fund_etf_hist_min_em()` | ETF分时行情 | 1/5/15/30/60分钟，支持前/后复权 |
| `fund_etf_category_ths()` | ETF实时行情-同花顺 | 16列：净值、累计净值、增长率、申购赎回状态 |

| `fund_info_index_em()` | 指数型基金信息 | 净值、手续费、起购金额、跟踪标的、跟踪方式 |

| `fund_etf_category_sina()` | ETF行情-新浪 | 13列 |

## 三、关键ETF分析指标

### 3.1 价格与交易指标
- IOPV（基金份额参考净值，每15秒更新）
- 折价率/溢价率 = (现价 - IOPV) / IOPV × 100%
- 成交量、成交额、换手率、量比
- 委比、外盘、内盘
- 主力净流入/净占比、超大单/大单/中单/小单净流入

### 3.2 收益与风险指标
- 近1周/1月/3月/6月/近1年/近2年/近3年/今年来/成立来收益率
- 年化波动率
- 夏普比率
- 最大回撤
- 索提诺比率
- Calmar比率

### 3.3 评级体系
- 上海证券评级
- 招商证券评级
- 济安金信评级
- 晨星评级
- 天相评级

### 3.4 持仓与配置
- 股票持仓明细及占比
- 债券持仓
- 行业配置
- 资产配置
- 持有人结构（机构/个人）
- 规模变动趋势
- 基金换手率

### 3.5 跟踪误差
- 年化跟踪误差
- 与基准指数对比走势

## 四、与我们现有系统的对比

### 4.1 我们已有的能力（etf-platform）

| 模块 | 已有功能 |
|------|----------|
| 数据获取 | AKShare接口、东财/新浪/同花顺数据源 |
| 七层穿透评分 | L1-L20共15+个分析层 |
| 量化因子 | 宏观周期、因子加载、波动率、VaR、微观结构等 |
| 决策引擎 | 策略锦标赛、ML预测、仓位分配、风险评估 |
| 回测系统 | 合成回测、预测回测、CVaR组合优化 |
| 监控巡逻 | 每日巡逻、价格监控、新闻桥接 |
| 知识体系 | 170+知识库条目、投资理论框架 |

### 4.2 东方财富/天天基金特色（我们需要学习/借鉴的）

| 缺失/薄弱点 | 说明 |
|-------------|------|
| 折溢价/IOPV实时监控 | 我们的data层有实时价格桥接，但缺少IOPV折溢价分析模块 |
| 资金流向深度分析 | 东财有主力/超大单/大单/中单/小单净流入，我们缺少这个维度 |
| 同类排名/四分位排名 | 东财提供同类基金排名和百分比排名走势 |
| 基金评级整合 | 四家评级机构（上证/招商/济安/晨星） |
| 持仓明细展示 | 东财有完整的股票/债券持仓、行业配置、持有人结构 |
| 收益测算器 | 基于申购金额和过往业绩的收益模拟 |
| 定投计算器 | 定投与单笔投资收益比较 |
| ETF筛选器 | 多维条件组合筛选（规模/费率/评级/收益/风格） |
| 社区情绪 | 基金吧讨论热度（可作为情绪因子） |
| 分红/拆分历史 | 完整的分红配送和拆分记录 |

## 五、改造建议方向

1. **新增折溢价监控模块** - 基于IOPV实时计算ETF折溢价率
2. **新增资金流向分析层** - 整合主力/大单/中单/小单净流入数据
3. **新增同类排名模块** - 计算ETF在同类中的百分位排名
4. **新增评级整合层** - 接入四家评级机构数据
5. **增强持仓分析** - 从季报/年报提取持仓并计算重叠度
6. **新增收益测算器** - 交互式收益模拟
7. **增强ETF筛选器** - 多维条件组合筛选
8. **新增基金吧情绪因子** - 作为L16实时信号层的补充
